## 아키텍처

**두 축 융합 — 생성 흔적(축 A) + 농업적 정합성(축 B) → 가중합 → 임계값 판정** (`docs/02` §4)

![시스템 구조](docs/assets/architecture.png)

```
입력 이미지(원본 해상도)
  ├─ 축 A · 생성 흔적   A1 잠재-디코더 │ A2 스펙트럼 │ A3 양자화 │ A4 영역 대조 │ A5 전역 모델
  ├─ 작물 분할 → 마스크 M ─┬→ A4 (영역 정의)
  │                        └→ 축 B (누끼)
  ├─ 축 B · 농업 정합성  B1 형태 │ B2 시설 구조물 │ B3 생육 정합
  └─ score = Σw·A + Σv·B  →  score ≥ τ 이면 생성 이미지
```

판별 근거가 성격이 다른 두 곳에 나뉘어 있다는 관찰에서 출발한다 — **생성 과정이 픽셀에 남긴 기술적 흔적**과 **실제 작물이라면 지켜야 할 농업적 규칙**. 두 축을 독립적으로 세우고 가중합하므로 한 축이 무너져도 다른 축이 남는다.

설계안 비교(A~D)와 그 근거는 [`docs/07`](docs/07-설계안-비교.md).

## 핵심 결론 요약

1. **VAE 디코더는 생성 계열을 가로지르는 공용 부품이다.** 확산·플로우 매칭·증류·잠재 인페인팅은 전부 마지막에 같은 디코더를 통과하므로, **지표 하나(A1)가 네 계열을 동시에 겨냥한다.** 운영측 생성기가 비공개라는 근본 난제에 대한 주된 대비책이다.
2. **작물 분할은 한 번, 용도는 두 개.** 마스크를 축 B에서는 "누끼"로, A4에서는 "영역 정의"로 쓴다. **분할 비용은 1회인데 판별 근거는 둘이 된다.** 단 작물만 잘라 파이프라인 전체를 통과시키면 유형 ①②에서 판별 근거를 스스로 제거하게 되므로, 누끼는 축 B 앞단에만 둔다.
3. **유형 ①②는 둘로 갈린다.** 픽셀 공간 합성(알파·Poisson)은 배경을 안 건드려 영역 불일치가 남으므로 A4가, 잠재 공간 인페인팅은 이미지 전체가 재디코딩돼 영역 대조가 무력하므로 A1이 담당한다. **둘 중 하나만으로는 절반만 잡는다.**
4. **계열 분류는 판정 경로에 두지 않는다.** Model attribution은 대부분 closed-set이라 미지 생성기에서 오라우팅하고, 그 오류가 판정으로 전파된다. 계열 지식은 *지표 설계*에 쓰고 런타임 분기에는 쓰지 않는다.
5. **축 B가 이 팀의 무기다.** 실제 이미지만으로 학습되어 미지 생성기와 무관하고, 재압축이 잎맥 위상을 바꾸지 못해 후처리에 강하며, 발표평가 30점과 농업해석상에 직결된다.
