# ai-grit — 제1회 전국 농과계 대학 농업 AI 경진대회

**시설작물 이미지 신뢰성 판별 미션**(실제 현장 촬영 이미지 vs 생성 이미지 이진 분류) 준비 저장소.

- 주최: (사)한국농업기계학회, 한국농기계공업협동조합
- 공동주관: (사)한국농업기계학회, 전북대학교 농업기계ICT융합연구소
- 서류 접수: ~2026. 9. 9.(수) 23:59 / 온라인대회: 9. 21.(월) ~ 10. 18.(일) / 발표·시상: 11. 6.(금), 대구 EXCO
- 배점: 온라인 정량평가 70점(정형 40 + **이미지 30**) + 현장 발표평가 30점

이 저장소는 **이미지 미션**만 다룬다. 정형데이터 미션은 범위 밖.

---

## ⚠️ 저장소 취급 주의

공고문 p.9: *"대회 운영 측이 제공한 데이터는 대회 수행 목적으로만 이용하여야 하며, 제3자에게 제공하거나 온라인에 공개·배포할 수 없음"*

- **운영측 제공 예시 이미지·테스트 데이터·베이스라인 데이터를 이 저장소에 커밋하지 말 것.** 저장소가 public이면 즉시 규정 위반이다.
- 대회 이미지를 외부 AI 서비스·검증 API·클라우드 스토리지에 업로드하지 말 것. 개발 단계의 분석도 전부 로컬에서 수행한다.
- 데이터 경로는 `.gitignore`로 차단하고, 코드에는 경로만 참조한다.

## 핵심 결론 요약

1. **초기 구상(YOLO 작물 검출 → 누끼 → 고주파 분석)은 규정 위반이 아니지만, 공고문이 명시한 생성 4유형 중 합성형 2유형에서 구조적으로 실패한다.** 위조 증거가 배경과 경계에 있는데 그 부분을 잘라내기 때문이다.
2. 세그멘테이션은 버리지 말고 **"잘라내기" → "마스크 안/밖 통계 대조"** 로 용도를 바꾼다. 그러면 그 2유형의 핵심 무기가 된다.
3. 핵심 가설은 **"가짜를 배우지 말고 진짜를 배운다"** 이다. 운영측 생성기가 비공개이므로, 시설작물이라는 좁은 도메인의 *실제 이미지 정상 분포*를 정밀 학습해 이탈을 탐지하면 미지 생성기 일반화 문제를 우회할 수 있다.
