【양식 2】 수행계획서 — 이미지 미션 부분 조립 안내

■ 파일
  수행계획서_이미지미션.txt   본문 (공백 제외 1,546자 ≈ A4 1장)
  구조도.png                  인쇄용 도식 (4200x2514, 3배 해상도)
  구조도.svg                  벡터 원본 (색·문구 수정용)

■ 배치 권장
  A4 1쪽 : 1~2장 본문 + 구조도 (2장 "수행 구조" 자리에 삽입)
  A4 0.5쪽: 3~5장 본문
  → 이미지 미션 전체 약 1.5쪽. 나머지 1.5쪽에 팀 구성·역할분담과
    정형데이터 미션을 배치하면 공고문 p.12의 3쪽 제한에 들어간다.

■ 서식 권장
  본문 10pt / 줄간격 160% / 여백 보통
  구조도는 폭 100%(약 16cm)로 넣으면 글자가 또렷하게 보인다.
  더 줄여야 하면 폭 12cm까지는 판독에 문제 없다.

■ 주의
  - 본문에 팀명·팀원 정보는 없다. 양식 상단 기본정보란에 별도 기재.
  - "A1/A2/A4/A5, B1/B2/B3" 기호는 본문과 도식이 서로 대응한다.
    한쪽만 고치지 말 것.
  - 도식을 흑백 인쇄해도 판독된다(색 외에 굵기·위치로 구분).
