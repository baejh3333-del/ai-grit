■ ML 모델

  이미지: 생성 흔적 지표(VAE 재구성 오차·주파수 분석·영역 대조 CNN·FerretNet)와
  농업 정합성 지표(잎맥 그래프·구조물 주기성·One-Class 이상탐지)의 가중합 앙상블
  정형: 〔담당 팀원 작성〕

■ 이미지 데이터

• 문제: 운영 측이 사용한 생성 모델이 비공개이고 생성 유형에 따라 판별 근거의
  위치가 달라, 단일 분류기로는 자체 생성 데이터에 과적합되어 미학습 생성
  모델에서 성능이 붕괴할 가능성 존재

• 대응: 생성 흔적 축과 농업 정합성 축을 독립 구성해 가중합함. 전자는 잠재 생성
  모델이 공통으로 거치는 VAE 디코더의 재구성 오차로 여러 계열을 동시에 겨냥하고,
  분할 마스크를 잘라내기가 아닌 영역 정의로 사용해 마스크 안팎의 노이즈·색온도·
  조명 차이를 대조함으로써 부분 합성 유형에 대응함. 후자는 잎맥 위상과 시설
  구조물의 직선·주기성 등 실제 작물이 지켜야 할 규칙을 실제 이미지만으로 학습해
  생성 모델 종류와 무관한 판별 경로를 확보함. 학습에 사용하지 않은 생성 계열로
  평가하는 Leave-One-Generator-Out 교차검증으로 미학습 이미지에 대한 일반화
  성능을 사전 검증함.
