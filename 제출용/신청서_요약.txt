■ ML 모델

  이미지: 생성 흔적 축과 농업 정합성 축의 두 갈래 지표를 가중합하여 판정하는
  앙상블 구조. 생성 흔적 축은 VAE 재구성 오차, FFT 기반 주파수 스펙트럼 분석,
  이중스트림 CNN(RGB+노이즈 잔차) 자체 학습, FerretNet 파인튜닝, DINOv2 선형
  분류기로 구성하고, 농업 정합성 축은 잎맥 그래프 특징, Hough 변환 기반 직선·
  주기성 검출, One-Class SVM/Isolation Forest 이상탐지로 구성함.
  작물 분할은 MobileSAM 1회 수행 후 두 축에 공용으로 사용함.

  정형: 〔담당 팀원 작성〕

■ 이미지 데이터

• 문제: 운영 측이 사용한 생성 모델이 비공개이므로, 자체 생성 데이터로만
  지도학습할 경우 해당 생성 모델의 아티팩트에 과적합되어 미학습 생성 모델에서
  성능이 붕괴할 가능성 존재

• 대응: 생성 계열을 가로지르는 공통 단서를 주력 지표로 채택함. 확산·플로우
  매칭·증류·잠재 인페인팅은 최종 단계에서 모두 VAE 디코더를 통과하므로, 그
  재구성 오차 하나로 네 계열을 동시에 겨냥함. 아울러 실제 이미지만으로 학습
  가능한 농업 정합성 축을 병행하여 생성 모델 종류와 무관한 판별 경로를 확보함

• 문제: 생성 유형 중 실험실 작물과 현장 배경을 결합한 이미지, 현장 작물과
  다른 현장 배경을 결합한 이미지는 대부분이 실제 촬영 픽셀인 부분 합성이므로,
  작물 영역만 분리하여 분석하는 접근으로는 판별 근거가 남지 않음

• 대응: 작물 분할 마스크를 잘라내기가 아닌 영역 정의에 사용하여, 마스크 안팎의
  노이즈 잔차·JPEG 블록 정렬·색온도·초점·조명 방향 차이를 대조함. 동일 마스크를
  농업 정합성 축의 작물 분리에도 재사용하여 분할 비용은 1회로 유지함

• 문제: 자체 생성물은 PNG, 수집 실제 이미지는 JPEG로 저장되기 쉬워 모델이
  진위가 아닌 압축 여부를 학습할 위험이 있으며, 리사이즈는 보간을 수반하여
  생성 흔적을 훼손함

• 대응: 실제·생성 양측에 동일한 압축·리사이즈·블러 증강을 대칭 적용하여 압축
  기반 지름길을 차단하고, 전 과정에서 리사이즈 대신 원본 해상도 크롭을 사용함

• 문제: 생성 방식, 작물, 배경 및 촬영 환경에 따라 이미지 특성이 달라 특정
  데이터에 과적합될 가능성 존재

• 대응: 카메라·농가·시기의 다양성을 의도적으로 확보하고, 학습에 사용하지 않은
  생성 계열로 평가하는 Leave-One-Generator-Out 교차검증과 특정 농가·카메라를
  제외한 평가를 병행하여 미학습 이미지에 대한 일반화 성능을 사전 검증함.
  생성 유형별 성능을 항상 분리 측정하여 전체 평균에 가려지는 취약 유형을 식별함
