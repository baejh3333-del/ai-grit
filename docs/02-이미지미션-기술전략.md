# 02. 이미지 미션 기술 전략

---

## 1. 문제 재정의 — 이것은 단일 문제가 아니다

공고문 p.4가 정의한 생성 이미지 유형을 포렌식 문헌의 문제 유형으로 옮기면 다음과 같다.

| 공고문 유형 | 실질 | 대응 연구 분야 | 위조 영역 |
|---|---|---|---|
| ① 실험실 작물 + 현장 배경 | 이미지 합성(splicing/compositing) | IFDL (Image Forgery Detection & Localization) | **국소** — 작물 영역이 이식됨 |
| ② 현장 작물 + 다른 현장 배경 | 이미지 합성 | IFDL | **국소** — 작물 픽셀은 진짜 |
| ③ 실제 이미지의 스타일 변환 | 전역 img2img 변환 | AIGI 탐지 + 재구성 오차 | **전역** (저수준만 변함) |
| ④ 전체 생성 | 완전 합성 | AIGI 탐지 | **전역** |

**핵심 통찰:** 이 미션은 "AI 생성 이미지 탐지(AIGI)" 하나가 아니라 **AIGI 탐지 + 부분 위조 국소화(IFDL)의 혼합 문제**다.
①②는 대부분의 AIGI 벤치마크에 존재하지 않는 문제 유형이며, 전역 분류기로는 원리적으로 약하다. 합성 이미지는 **픽셀의 대부분이 진짜**이므로 전역 평균 스코어가 희석되기 때문이다.

이 구분이 이후 모든 설계 결정의 근거가 된다.

## 2. 초기 구상의 한계 분석

초기 구상: `YOLO로 작물 검출 → 작물만 누끼 → 고주파 특성으로 생성 여부 판별`

### 2.1 치명적 결함 — 유형 ①②에서 판별 근거를 스스로 제거한다

- **유형 ②는 작물 픽셀이 실제 촬영물이다.** 누끼로 작물만 남기면 남는 것은 진짜 픽셀뿐이고, 어떤 분류기를 붙여도 "real"로 갈 수밖에 없다.
- **유형 ①도 실험실 작물 픽셀 자체는 실제 사진이다.** 판별 단서는 작물 영역 *내부*가 아니라 **작물과 배경의 불일치**에 있다:
  조명 방향, 색온도·화이트밸런스, 노이즈 레벨, 초점/피사계심도, 그림자 유무와 방향, 원근·스케일 정합성, JPEG 압축 이력.
  여기에 **경계의 블렌딩 흔적**(알파 경계, 하모나이제이션 자국, 인페인팅 잔물결)이 더해진다.
- 즉 **증거는 "작물 영역"이 아니라 "영역 간 관계와 배경"에 있다.** 크롭은 그 관계를 파괴한다.

배점상 유형 ①②가 테스트셋의 절반을 차지한다면, 이 파이프라인은 그 절반을 통째로 놓친다.

### 2.2 부차적 한계

| # | 한계 | 설명 |
|---|---|---|
| 1 | **리사이즈가 고주파 흔적을 지운다** | 최근 연구의 합의는 명확하다 — resize는 resampling/보간을 수반해 생성 과정이 남긴 미세 고주파 흔적을 훼손하므로, down-sampling 대신 **crop**을 써야 한다(SAFE). 누끼 후 정사각 리사이즈는 정확히 이 금기를 범한다. |
| 2 | **알파 매팅이 인공 고주파를 주입한다** | 매트 경계의 보간·안티에일리어싱이 새로운 고주파를 만든다. 마스크 품질이 진짜/가짜에서 체계적으로 다르면(가짜 합성물의 경계가 더 선명한 경향) 통제되지 않은 교란 변수가 된다. |
| 3 | **검출기 오류가 그대로 전파된다** | 시설작물은 캐노피가 화면 대부분을 채우는 경우가 많아 "작물 검출"이 부정확하거나 애초에 무의미하다. 미검출 시 폴백이 정의되지 않으면 비공개 테스트셋에서 미정의 동작이 발생한다. |
| 4 | **검출기 편향이 분류로 샌다** | 검출기는 실제 이미지로 학습되어 생성 이미지에서 검출률·박스 품질이 달라진다. 그 차이가 의도치 않은 신호로 새어 들어가 검증 불가능한 성능을 만든다. |
| 5 | **고주파 단서는 미지 생성기에 취약하다** | GAN의 업샘플링 격자와 확산모델의 흔적은 성질이 다르고, 운영측 생성기는 비공개다. 저수준 단서에 크게 의존하는 계열(NPR 등)은 미지 생성기에서 무너지기 쉽고 JPEG 재압축·리사이즈에도 약하다. |
| 6 | **압축 shortcut** | 자체 생성물은 PNG, 수집한 실제 데이터는 JPEG이기 쉽다. 그러면 모델은 "AI 여부"가 아니라 "압축 여부"를 학습한다("Fake or JPEG?" 문제). 테스트셋이 균일 재인코딩되어 있으면 성능이 전멸한다. |
| 7 | **비용 대비 효과** | 3단 파이프라인은 Colab 자원·제출 용량·재현성 리스크를 모두 키운다. 배점은 30점이다. |

### 2.3 그러나 아이디어 자체는 살릴 수 있다

세그멘테이션은 버리는 것이 아니라 **용도를 바꾸는** 것이 정답이다.

> **크롭용 마스크 → 영역 정의용 마스크.**
> 작물 마스크 안/밖의 통계를 **대조**하면, 그것이 바로 유형 ①②를 정면으로 겨냥하는 splicing forensics가 된다.

고주파 분석도 마찬가지다. 버리는 것이 아니라 **원본 해상도 crop 위에서, 강한 압축 증강과 함께** 수행하도록 조건을 바꾼다. (§4 B0/B3)

## 3. 최신 연구 동향 대조 — 무엇을 쓰고 무엇을 버리는가

2024~2026 AIGI 탐지 동향을 이 대회의 제약(Colab 자원, 가중치 제출 의무, 추론 시 외부 접근 금지)에 대조한 결과.

### 3.1 규정상 사용 불가

| 기법 | 사용 불가 사유 |
|---|---|
| **QuAD** (근사 중복 이미지 스코어 가중 융합) | 추론 시 역이미지 검색이 필수 → p.5/p.10 "외부 데이터의 조회·다운로드를 통해 예측결과를 생성하는 행위" 위반 |
| **SynthID 워터마크 검증** | Google 검증 API 호출 필요(외부 API 금지) + 대회 이미지를 외부 서비스에 업로드하면 p.9 위반. 개발 단계 정찰로도 금지 |
| **C2PA 자격증명 연동** | 생성 시점의 선제적 방어 기술이라 판별자 입장에서는 무관. 파일 내 잔존 태그를 로컬에서 읽는 것만 가능하며 그마저 의존 금지(`01` §5) |

### 3.2 자원상 비현실적

| 기법 | 사유 | 대체 |
|---|---|---|
| **DIRE** (확산 재구성 오차) | 이미지당 수십 스텝 디노이징. 테스트 전량 추론이 Colab에서 불가능 | **AEROBLADE** — VAE 1회 왕복이면 충분하며, 인페인팅 영역 국소화까지 가능 |
| **FatFormer** (492M), **CO-SPY** (963M) | 제출 용량·추론 속도 부담이 크고 앙상블 멤버로는 과함 | CLIP linear probe(B1)가 유사 효과를 훨씬 싸게 제공 |

### 3.3 라이선스상 가중치 사용 불가

| 자산 | 사유 | 대체 |
|---|---|---|
| **TruFor / Noiseprint++** | GRIP-UNINA 독자 라이선스(All rights reserved, 비영리·정보 목적 한정) → 재배포 불가. 그런데 p.5는 가중치 제출을 예외 없이 요구 | **설계 아이디어만 차용**: RGB + 노이즈 잔차 이중 스트림, 신뢰도 맵 개념. 가중치는 우리 데이터로 자체 학습(B3) |
| **DINOv3** | Meta 독자 라이선스 | **DINOv2**(Apache-2.0) |

### 3.4 채택

| 자산 | 라이선스 | 역할 |
|---|---|---|
| **FerretNet** (NeurIPS 2025) | Apache-2.0 | 1.06M params. 자연 이미지의 국소 픽셀 의존성(LPD) 위반 탐지. 제출 용량·속도 모두 최적 → **1순위 베이스라인** |
| **SPAI** (CVPR 2025) | Apache-2.0 (**가중치 포함**) | 실제 이미지 스펙트럼 분포를 자기지도 학습 후 OOD 판정. 임의 해상도 입력 지원 → 리사이즈 금기와 정합 |
| **CLIP / DINOv2 + linear probe** | MIT / Apache-2.0 | UnivFD 계열. 미지 생성기 일반화의 주력 |
| **SAM / MobileSAM / SAM2** | Apache-2.0 | 영역 정의용 세그멘테이션 |

### 3.5 벤치마크 수치를 그대로 믿으면 안 되는 이유

공개된 비교표의 수치(FerretNet 97.1%, SAFE 96.8% 등)는 **ProGAN 4-class 학습 → ForenSynths 계열 벤치마크** 조건에서 산출된 것이다. 이 대회와는 두 가지가 결정적으로 다르다.

1. **콘텐츠 도메인이 시설작물 단일 도메인**이다. 웹 전반의 다양한 콘텐츠로 측정한 일반화 수치가 그대로 이식되지 않는다.
2. **유형 ①②가 부분 합성**인데, AIGI 벤치마크에는 이 유형이 사실상 없다.

→ **공개 순위를 그대로 채택하지 말고, 자체 검증셋(`03` 참조)에서 유형별로 재측정한 결과로 브랜치 가중치를 정한다.**

### 3.6 동향이 오히려 우리 설계를 뒷받침하는 지점

"이점 후 충돌(Benefit then Conflict)" 딜레마 — 훈련 소스의 다양성을 늘리면 어느 임계점까지는 성능이 오르지만, 그 뒤로는 서로 다른 아키텍처의 이질적 아티팩트가 특성 공간에서 겹치며 오히려 성능이 정체·하락한다.

이는 두 가지를 함의한다.
- **설계**: 이질적인 4유형을 하나의 end-to-end 분류기에 몰아넣으면 안 된다. → **유형별 브랜치 + 융합**이 옳다.
- **데이터**: "생성기 수를 무작정 늘리면 된다"는 순진한 전략은 기각된다. → 생성기를 계열별로 묶고, 추가할 때마다 LOGO CV로 실제 이득을 확인한다(`03`).

## 4. 권장 아키텍처

**설계 원칙**
1. **리사이즈 금지** — 원본 해상도에서 crop
2. **유형별 전문가** — 단일 모델로 4유형을 모두 잡으려 하지 않는다
3. **재배포 가능 라이선스만** — 가중치 제출 의무 때문
4. **미지 생성기 회피** — 가짜의 특징이 아니라 진짜의 정상성을 학습 (§5)

| 브랜치 | 내용 | 담당 유형 | 우선순위 |
|---|---|---|---|
| **B0** | **FerretNet 파인튜닝.** Apache-2.0, 1.06M params, 매우 빠름. 베이스라인이자 앙상블 상시 멤버 | ③④ (①② 부분 기여) | **1** |
| **B3** | **부분 합성 국소화.** 자체 학습 이중 스트림(RGB + SRM/Bayar 노이즈 잔차) + 마스크 안/밖 대조 + top-k MIL | **①②** | **2** |
| **B1** | **전역 의미 특징.** frozen CLIP ViT-L/14 또는 DINOv2 + linear probe (UnivFD 계열) | ③④ | 3 |
| **B2** | **스펙트럼 이상탐지.** SPAI 채택 또는 real-only 자기지도 자체 구현 | ③④ (①② 부분) | 4 |
| **B4** | **AEROBLADE.** SD/SDXL VAE 라운드트립 오차. 학습 불요 | ③ + LDM 기반 ①② | 5 (선택) |

**B3를 2순위로 두는 이유:** 유형 ①②는 다른 브랜치가 **전혀** 잡지 못하고, 테스트셋 기여도가 최대 절반일 수 있다. B0가 아무리 좋아도 여기서 막히면 상한이 생긴다.

### 4.1 B3 상세 — 초기 아이디어의 승화 형태

```
입력 (원본 해상도 유지)
  ├─ 세그멘테이션(SAM 계열) → 작물 마스크 M
  │     ※ 실패 시 균일 패치 격자로 자동 폴백
  ├─ 영역 대조 특징: M 안 vs M 밖의 차이
  │     (a) 노이즈 잔차 통계 (SRM/Bayar 필터 응답 분포)
  │     (b) JPEG 8x8 블록 그리드 정렬 및 양자화 흔적
  │     (c) 색온도 / 화이트밸런스 추정치
  │     (d) 초점·블러 척도 (라플라시안 분산, 국소 선예도)
  │     (e) 조명 방향 추정치
  ├─ 패치 격자 위조 스코어 → top-k MIL 풀링
  │     ※ 합성물은 대부분이 진짜이므로 전역 평균은 신호를 희석시킨다
  └─ 출력: 이미지 스코어 + 위조 히트맵
```

- **카메라 지문은 "일관성" 용도로만.** 실제 현장 이미지는 농가·시설에서 직접 촬영되므로(p.4) 카메라 종류가 제한적이고, PRNU/노이즈 지문이 잘 작동할 수 있다. 그러나 **"특정 카메라 = 진짜"로 학습하면 테스트셋의 미지 카메라에서 붕괴한다.** 반드시 *한 이미지 내부의 영역 간 일치 여부*로만 사용한다.
- **부산물의 가치:** 위조 히트맵은 발표평가(30점)에서 "왜 가짜로 판단했는가"를 시각적으로 설명하는 근거가 된다.

### 4.2 융합과 추론

- 브랜치 로짓 → 로지스틱 회귀 + 확률 캘리브레이션. 가중치는 LOGO CV로 결정한다.
- TTA: 원본 해상도 멀티크롭 + 좌우반전 평균. **리사이즈 기반 TTA는 쓰지 않는다.**
- 임계값: 평가지표가 미확정이므로 확률을 출력하고 0.5를 기본값으로 두되, 지표 확정 후 검증셋 기준으로 조정한다.
- 자원 초과 시 **단계적 축소**: fp16 → 크롭 수 축소 → 브랜치 축소(B4 → B2 → B1 순으로 제거). 이 순서를 사전에 문서화해 둔다.

## 5. 핵심 가설 — "가짜를 배우지 말고 진짜를 배운다"

이 대회의 근본 난제는 **운영측 생성기가 비공개**라는 것이다. 지도학습은 필연적으로 *우리가 만든* 생성기의 아티팩트에 과적합되고, 운영측이 다른 계열을 썼다면 그대로 무너진다.

그런데 최근 가장 강한 두 계열은 모두 **"실제 이미지의 정상성"을 모델링**한다.
- **SPAI**: 실제 이미지의 스펙트럼 분포를 자기지도로 학습한 뒤, 스펙트럼 재구성 유사도로 OOD 여부를 판정
- **FerretNet**: 마르코프 무작위장 이론에 기반해 자연 이미지가 지켜야 할 국소 픽셀 의존성의 위반을 탐지

**그리고 이 대회는 그 접근에 비정상적으로 유리한 조건을 갖는다.**

| 조건 | 일반 AIGI 연구 | 이 대회 |
|---|---|---|
| 콘텐츠 도메인 | 웹 전체 — 너무 넓어 "정상 분포"를 정의하기 어려움 | **시설작물 단일 도메인** |
| 실제 데이터 확보량 | 다양성 확보가 어려움 | **AI Hub 스마트팜만으로 수십만 장** |

→ **좁은 도메인의 "진짜 시설작물 이미지" 정상 매니폴드를 정밀하게 학습하면, 미지 생성기 일반화 문제 자체를 우회할 수 있다.**
일반 AIGI 연구가 도메인이 넓어서 못 하는 것을 우리는 할 수 있다는 뜻이다.

**구현**: real-only 자기지도 학습(스펙트럼 재구성 / 마스킹 잔차 예측) → 재구성 오차를 이상 스코어로 → 지도학습 브랜치와 융합.
**실패 시나리오 대응**: 운영측 생성기가 우리가 재현하지 못한 계열이면 이 브랜치의 가중치를 올린다.

이것이 서류평가가 명시적으로 요구하는 *"팀이 실제로 설정한 가설"*(p.6)이며, 발표평가의 차별화 포인트가 된다.

## 6. 예시 이미지 정찰(EDA) — 합법이며 결정적

운영측은 소수의 예시 이미지와 샘플 코드를 제공한다(p.4). 이를 **로컬에서** 분석하면 다음을 알 수 있다.

| 분석 항목 | 알 수 있는 것 |
|---|---|
| JPEG 양자화 테이블, 이중 압축 흔적 | 저장 파이프라인, 재인코딩 여부 |
| 해상도·종횡비 분포 | 생성 해상도(512/768/1024 등) 및 생성기 계열 추정 |
| EXIF/XMP 잔존 태그, PNG chunk | 생성 도구 서명, 촬영 기기 |
| ICC 프로파일 / 색공간 | 처리 경로 |
| 노이즈 레벨, 스펙트럼 형상 | 저수준 단서의 잔존 여부 |

**전략적 가치**
1. 생성기 계열이 특정되면 학습 데이터를 그 계열로 집중해 **"이점 후 충돌"을 회피하면서** 정확도를 올릴 수 있다.
2. **저수준 단서에 얼마나 베팅할지**가 결정된다. 균일 재인코딩되어 있으면 B0/B2 비중을 낮추고 B1/B3 비중을 올린다.
3. 실제/생성 이미지가 서로 다른 파이프라인을 거쳤다면 그것은 shortcut이며, 그 사실을 아는 것 자체가 **과적합 위험 관리**에 필요하다.

**제약 (반드시 준수)**
- 전부 로컬에서 수행한다. 대회 이미지를 외부 서비스·API에 업로드하면 p.9 위반이다.
- 추론 시에는 메타데이터에 의존하지 않는다. 정찰로 얻은 정보는 *학습 데이터 구성과 브랜치 가중치* 조정에만 쓴다.

## 7. 농업 도메인 특화 단서 (발표평가 30점 + 특별상)

정량 성능의 주력은 B0~B3에 두고, 아래는 **정성 분석 + 오분류 사례 해석**으로 붙여 발표 점수와 특별상(농업해석상, 생성데이터활용상) 경쟁력을 확보한다.

**식물학적 정합성** — 생성 모델이 자주 틀리는 지점
- 잎맥(venation)의 위상 구조, 엽서(phyllotaxis) 배열 규칙
- 딸기 수과(achene) 배열, 토마토 꽃받침 갈래 수, 화방(truss)의 착과 순서
- 과실 크기 대비 잎 크기의 스케일 정합성
- 병징(반점·황화·위조)의 해부학적 일관성 — 잎맥을 따라 번지는가, 무작위로 찍혀 있는가

**시설 구조물** — 생성 모델이 반복 구조와 직선에서 실패하는 지점
- 점적관수 라인, 로크울 배지, 유인줄·클립, 하이와이어
- 난방 배관 레일, 피복재 격자, 작물 라벨

이 단서들은 **정량 특징으로 일부 계량화**할 수도 있고(직선성·주기성 검출), 최소한 **오분류 사례 분석의 언어**로 사용해 "농업적 해석"(p.8-9 발표 평가항목) 점수를 확보한다.
