## 2. AI 생성 이미지 탐지 (AIGI)

### 채택 모델

- **FerretNet: Efficient Synthetic Image Detection via Local Pixel Dependencies** (NeurIPS 2025)
  <https://arxiv.org/abs/2509.20890> · 저장소(Apache-2.0): <https://github.com/xigua7105/FerretNet>
  마르코프 무작위장 기반 국소 픽셀 의존성(LPD) 분석. 1.06M 파라미터, 256² 입력, ProGAN 4-class 학습으로 22개 생성 모델 벤치마크 평균 97.1%.
  ※ 공식 가중치는 Baidu Disk 배포 — 접근성 사전 확인 필요.

- **Any-Resolution AI-Generated Image Detection by Spectral Learning (SPAI)** (CVPR 2025)
  <https://openaccess.thecvf.com/content/CVPR2025/html/Karageorgiou_Any-Resolution_AI-Generated_Image_Detection_by_Spectral_Learning_CVPR_2025_paper.html>
  저장소: <https://github.com/mever-team/spai> — **소스코드 및 모델 가중치 모두 Apache-2.0** (README 명시)
  실제 이미지 스펙트럼 분포를 자기지도 학습 후 스펙트럼 재구성 유사도로 OOD 판정. 임의 해상도 입력 지원.

- **AEROBLADE: Training-Free Detection of Latent Diffusion Images Using Autoencoder Reconstruction Error** (CVPR 2024)
  <https://arxiv.org/abs/2401.17879> · <https://github.com/jonasricker/aeroblade>
  LDM의 오토인코더가 자기 모델 생성물을 더 정확히 재구성한다는 성질 이용. 학습 불요, 인페인팅 영역 국소화 가능.

### 방법론 배경

- **Towards Universal Fake Image Detectors that Generalize Across Generative Models (UnivFD)** (CVPR 2023)
  동결 CLIP 특징 + 선형 분류기만으로 교차 생성기 일반화. 이후 파운데이션 모델 기반 탐지의 출발점.
  저장소: <https://github.com/WisconsinAIVision/UniversalFakeDetect>

- **Improving Synthetic Image Detection Towards Generalization: An Image Transformation Perspective (SAFE)**
  <https://arxiv.org/html/2408.06741v1>
  **리사이즈 금지 근거.** down-sampling을 crop 연산으로 대체(학습 RandomCrop / 추론 CenterCrop)해야 미세 아티팩트가 보존된다는 실험적 근거.

- **Fake or JPEG? Revealing Common Biases in Generated Image Detection Datasets**
  <https://arxiv.org/pdf/2403.17608>
  **압축 shortcut 근거.** JPEG 압축 증강이 "PNG=가짜 / JPEG=진짜" 지름길을 차단한다.

- **Community Forensics: Using Thousands of Generators to Train Fake Image Detectors** (CVPR 2025)
  <https://openaccess.thecvf.com/content/CVPR2025/html/Park_Community_Forensics_Using_Thousands_of_Generators_to_Train_Fake_Image_CVPR_2025_paper.html>
  4,803개 생성기, 270만 장. 생성기 다양성이 일반화에 기여함을 보인 대규모 데이터셋.

- **Is AI Generated Image Detection a Solved Problem?** <https://arxiv.org/pdf/2505.12335>
- **Methods and Trends in Detecting AI-Generated Images: A Comprehensive Review** <https://arxiv.org/pdf/2502.15176>
- **How well are open sourced AI-generated image detection models out-of-the-box: A comprehensive benchmark study** <https://arxiv.org/html/2602.07814v1>
  → 공개 탐지기의 out-of-the-box 성능이 도메인 이동 시 크게 떨어진다는 근거. 벤치마크 수치를 그대로 이식하면 안 되는 이유.

- **NTIRE 2026 Challenge on Robust AI-Generated Image Detection in the Wild**
  <https://arxiv.org/pdf/2604.11487>
  42개 생성기, 36가지 열화 파이프라인. 강건성 스윕 설계의 참고 규격.

## 3. 부분 위조 탐지·국소화 (IFDL) — 유형 ①② 대응

- **TruFor: Leveraging All-Round Clues for Trustworthy Image Forgery Detection and Localization** (CVPR 2023)
  <https://github.com/grip-unina/TruFor>
  RGB + Noiseprint++ 이중 스트림, 위조 맵 + 무결성 점수 + 신뢰도 맵 동시 출력.
  ⚠️ **라이선스**: GRIP-UNINA 독자 라이선스. *All rights reserved*, 비영리·정보 목적 한정 → **가중치 재배포 불가**.
  본 대회는 가중치 제출이 의무이므로 **설계 아이디어만 차용하고 가중치는 자체 학습**한다.

- **Noiseprint: a CNN-based camera model fingerprint** <https://github.com/grip-unina/noiseprint>
  카메라 모델 지문. 영역 간 일관성 검사의 이론적 배경. 동일 라이선스 제약.

- **IML-ViT: Benchmarking Image Manipulation Localization by Vision Transformer** <https://arxiv.org/pdf/2307.14863>
- **MVSS-Net: Multi-View Multi-Scale Supervised Networks for Image Manipulation Detection** <https://arxiv.org/pdf/2112.08935>
  JPEG 압축·노이즈·블러에 대한 강건성 평가 프로토콜의 표준.
- **IMDL-BenCo: A Comprehensive Benchmark and Codebase for Image Manipulation Detection & Localization** (NeurIPS 2024 D&B)
  <https://arxiv.org/pdf/2406.10580> — IFDL 모델 구현·평가 통합 코드베이스.
- **DINOv3 Beats Specialized Detectors: A Simple Foundation Model Baseline for Image Forensics**
  <https://github.com/Irennnne/DINOv3-IML> — 동결 파운데이션 모델 + 9.1M 학습 파라미터로 SOTA.
  ⚠️ DINOv3는 Meta 독자 라이선스 → 본 대회에서는 **DINOv2(Apache-2.0)로 대체**.
