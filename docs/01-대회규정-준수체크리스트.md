## 1. 이미지 미션 요구사항 (p.4, p.7)

- 대상 작물 이미지가 **실제 현장 이미지인지 생성 이미지인지 판별하는 이진 분류 모델**
- 실제 현장 이미지 = 농가 또는 시설에서 **직접 촬영된** 작물 이미지
- 생성 이미지에 포함될 수 있는 유형 4가지:
  1. **실험실 작물 + 현장 배경** 결합 이미지
  2. **현장 작물 + 다른 현장 배경** 결합 이미지
  3. 실제 이미지의 **스타일 변환** 이미지
  4. **전체 생성** 이미지
- 제출물: Google Colab에서 **실행 가능한 추론 코드 + 학습 완료 모델 + 관련 설정파일**
- 평가: 참가팀에 **공개하지 않은** 테스트 이미지를 운영 플랫폼 평가환경에서 자동 추론
- 제약: **일반적인 Google Colab 자원 범위**에서 정상 실행되어야 함

> 세부 평가지표·점수 환산·제출 횟수·기술적 제출 규격은 **개막설명회(9/18)에서 안내**된다. 미확정 사항은 `03` 문서 말미의 질문 리스트로 관리한다.

## 3. 모델·자산 라이선스 매트릭스

**왜 중요한가:** p.5는 *"평가에 필요한 사전학습 모델, 최종 모델 가중치 및 관련 설정파일은 제출자료에 포함하여야 하며"* 라고 **예외 없이** 요구한다. 재제출 갈음 예외("출처·접근경로·버전 제출로 갈음")는 **데이터에만** 적용된다. 게다가 p.10은 주최·주관기관의 **무상·비독점 이용권**을 규정한다.
→ **재배포가 불가능한 라이선스의 가중치는 이 대회에서 구조적으로 사용할 수 없다.**

## 5. 메타데이터 취급 원칙

파일 메타데이터(EXIF/XMP, JPEG 양자화 테이블, PNG chunk, ICC 프로파일)는 **개발 단계의 정찰 정보로만** 쓰고 **추론 로직이 의존하게 만들지 않는다.**

- 근거 1: 운영측이 테스트 이미지를 균일하게 재인코딩하면 단서가 사라져 성능이 붕괴한다.
- 근거 2: 반대로 실제/생성 이미지가 서로 다른 저장 파이프라인을 거쳤다면 그것은 **데이터셋 편향(shortcut)** 이며, 이에 의존한 모델은 일반화 실패로 최종 검증(p.8)에서 문제가 될 수 있다.
- 활용 방식: 예시 이미지의 메타데이터를 **로컬 분석**해 생성기 계열과 재인코딩 여부를 추정하고, 그 결과로 *학습 데이터 구성과 브랜치 가중치*를 조정한다. 추론 입력으로는 픽셀만 사용한다.

## 6. 재현성 요구사항 (p.8, p.10)

최종 검증은 **재현 가능성과 규정 준수 여부**를 본다. 재현되지 않으면 성적이 무효 처리될 수 있다.

- 시드 고정: `torch.manual_seed`, `numpy.random.seed`, `random.seed`, `torch.use_deterministic_algorithms(True)`
- `cudnn.benchmark = False`, `cudnn.deterministic = True`
- 추론에 무작위성이 필요하면(TTA 등) 시드를 고정하고 결과의 결정성을 검증
- 보관 항목: 실제 활용한 **학습데이터 목록**, 전처리·학습·추론 코드, 모델 및 설정파일, 실행환경(버전 고정된 requirements), 실행방법
- 제출기한 이후 수정은 **동일 예측결과 재현을 위한 실행환경·경로·설정 수정에 한정**된다(p.10). 모델 구조·가중치·예측결과를 바꾸는 보완은 허용되지 않으므로, **기한 내에 완결된 상태로 제출**해야 한다.

## 7. 제출 전 최종 체크리스트

- [ ] 네트워크 차단 상태에서 추론 스크립트 완주 확인
- [ ] 모든 가중치가 제출물 내 로컬 경로에서 로딩됨
- [ ] 제출물 총 용량이 Colab 자원 범위 내 (설명회 고지 한도 준수)
- [ ] **무료 Colab 등급 GPU에서 테스트 규모 추론 완주 + 소요 시간 측정** — 한도의 50% 이내여야 한다. **초과 시 제출 *전에* 지표를 뺀다**(p.10상 제출 후 구조 변경 불가, `08` F6)
- [ ] 원본 해상도 입력에서 A1 타일 왕복이 VRAM 안에서 도는지 확인
- [ ] AGPL 등 재배포 제한 자산 미포함 — `THIRD_PARTY_NOTICES.md`와 대조
- [ ] 외부 데이터·생성 데이터의 출처·이용조건·생성방법·활용방법 문서화 완료
- [ ] 시드 고정, 동일 입력에 대한 예측 재현성 2회 이상 확인
- [ ] 대회 제공 데이터가 저장소·제출물 외부로 나가지 않았음 확인
- [ ] 이미지 미션과 정형데이터 미션 **각각** 유효 제출 완료 (미제출 미션은 0점, p.7)
